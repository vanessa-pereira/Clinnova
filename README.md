## Clinnova

Initial clinical models and implementation guides for clinnova project (http://clinnova.lu) will be posted here and later merged to official github.

Clinnova uses REDCap nativelly. Expected approach is to use openEHR archetypes to map the data in a later stage. The models will be saved here, along with the terminologies codesystems and valuesets used for the different cohorts.
